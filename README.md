
# Oxide Launcher

Oxide Launcher installs, updates, and runs Oxide, our Rust port of Minecraft Beta 1.7.3.

Available for **Windows, macOS, and Linux**.

<img width="997" height="675" alt="oxide_launcher2" src="https://github.com/user-attachments/assets/53dc7745-9b76-4d21-b25c-f3b83f89758d" />

### Features:
- **Cross-Platform Support**: Runs on Windows, macOS (Intel and Apple Silicon), and Linux.
- **Auto Updates**: Automatically updates both the launcher and client.
- **Launch Options**: Provides an easy interface for customizing launch options.
- **Offline Play**: Use any username you wish. No Microsoft sign-in required.
- **Logging**: Easy access to client logs for bug reports.

> [!NOTE]
> Development is AI-assisted, but the final product is reviewed and tested by experienced human programmers.
