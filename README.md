# Oxide Launcher

Oxide Launcher installs, updates, and runs Oxide, our Rust port of Minecraft Beta 1.7.3. Play with an offline username or point the launcher at a local build.

### Features:
- **Auto Updates**: Will update the client and itself automatically.
- **Launch Options**: Provides an easy interface for customizing launch options.
- **Offline play** with a username of your choice. No Microsoft sign-in required.
- **Logging**: Easy access to client logs for bug reports.

> [!NOTE]
> Development is AI assisted but the final product is reviewed and tested by experienced human programmers.
